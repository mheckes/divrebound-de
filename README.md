# divrebound-de

Leitet divrebound.de auf https://divrebound.com weiter (GitHub Pages mit eigener Domain,
damit die Weiterleitung auch per HTTPS funktioniert). Die eigentliche Seite liegt in
[mheckes/DivRebound](https://github.com/mheckes/DivRebound).

`404.html` ist eine Kopie von `index.html`: GitHub Pages liefert sie für jeden unbekannten
Pfad aus, dadurch wird z. B. divrebound.de/impressum/ auf divrebound.com/impressum/ weitergeleitet.
